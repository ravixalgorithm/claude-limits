# claude-limits

A Claude Code plugin that shares the logged-in account's 5-hour and weekly limits on your group's page, and shows them in your status line.

Install it with the one-line command you were sent (it includes your group's connection code), then restart Claude Code. On Windows, paste it into Command Prompt and make sure Python is installed.

Limits upload while you use Claude Code, for whichever account is logged in. If you already have your own status line, the plugin leaves it alone and doesn't share.
